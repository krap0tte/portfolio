# Images

Placez vos photos ici au format JPG ou WebP.

Nommage recommandé : `photo-01.jpg`, `photo-02.jpg`, etc.

## Conseils

- **Format** : JPG (qualité 85–90) ou WebP pour de meilleures performances
- **Taille** : 1800–2400px de large pour les grands écrans
- **Poids** : visez < 500 Ko par image (utilisez [Squoosh](https://squoosh.app) pour optimiser)

Les images sont référencées dans les fichiers `_photos/*.md` via le champ `image`.
